# Figma components documentation creator

This Figma plugin facilitates the identification and organization of components within a Figma file. It can detect all components and component sets either from the current selection or from the entire document when no selection is made. The plugin offers functionality to automatically generate documentation for these components. It can render this documentation either on the existing page or create a new page specifically for this purpose, thus enhancing the management and presentation of design components in Figma.

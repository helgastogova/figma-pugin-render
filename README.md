# Background Remover for Figma

A Figma plugin that uses AI to automatically remove backgrounds from images. Powered by the RMBG-1.4 model, it provides a simple and efficient way to remove backgrounds directly in Figma.

## How It Works

1. Select any image in your Figma file
2. Run the plugin
3. Wait for the AI to process your image
4. Get your image with the background removed

The plugin uses advanced AI technology to identify and remove backgrounds while preserving the quality and details of the main subject.

## Features

- **One-Click Background Removal**: Remove backgrounds from images with just one click
- **AI-Powered**: Uses state-of-the-art AI model (RMBG-1.4) for accurate results
- **Preserves Quality**: Maintains image quality while removing backgrounds
- **Batch Processing**: Process multiple images at once (coming soon)
- **User-Friendly**: Simple and intuitive interface
